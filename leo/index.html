The fix
One permanent 301 from every version of leoburnett.ca (http, https, www, no www) straight to the same path on https://leotoronto.com, set at the DNS or edge layer. Paths already carry over, so /lb-toronto-best-of-the-best-and-most-awarded-at-the-cmas lands on the right page. It just takes four steps to get there. Then add leoburnett.ca as a "change of address" in Search Console.
